# ☕ Coffee Health Analytics

Interactive Streamlit dashboard analyzing how coffee consumption relates to sleep, heart rate, BMI and stress. Coursework project in Applied Informatics.

## Features

- Filtering by country, age, gender, stress level and coffee intake
- Correlation analysis and interactive charts
- Random Forest models predicting sleep, heart rate and BMI
- K-means clustering of respondents

## Dataset

`coffee_health_10000.csv` contains 10,000 synthetic records. Results are for demonstration only.

## Tech Stack

Python, Streamlit, pandas, scikit-learn, Plotly

## Run

```bash
pip install -r requirements.txt
streamlit run coffee-health-code.py
```
Note: the dashboard interface is in Russian
